Part 3 MVC web application
Brief description of the system Race_Day is an full-stack web-based event management system created for events such as Soweto Marathon. It involves two main users which are the organisers who creates,updates and deletes these events while also displaying an image for the event using the category which these events belong too, they also capture the participants' results. Participants create a user profile, browse events, enter event by selecting a category and tracking their enrolment in the event along with finishing posistions.

Part 3 of this system involves how MVC will power the front-end RaceDay system and have a web application the users can interact with and Part2 will work together with Part 3 as the backend with API to handle all the data operations,enforce role-based access and fully tested.
